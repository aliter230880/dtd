## Текущее состояние (27.08.2026)

### Работает (проверено)

- Полный цикл сделки в вебе и Android: создание с фото/файлами, отклики,
  выбор перевозчика, доставка, завершение, отзывы, чат, споры
- Авторизация: email + Google/Facebook/Apple; вход после выхода починен
  (был блокер), Google-вход переведён на `signInWithProvider` (ошибка 12500
  устранена), висение после соцвхода — `reloadUserDocument` с таймаутом
- Геокодирование в браузере (кросс-платформенный `GeocodingService`):
  адрес строкой и кликом по карте
- Роль в профиле; страница КУС-верификации доступна из профиля перевозчика,
  подписи на месте (11 ключей локализации)
- Пополнение кошелька через Stripe Checkout на всех платформах:
  50/100/500 и «своя» от $50 до $10 000; карта, Apple/Google Pay, SEPA,
  Klarna (PayPal, Wise/Revolut — помечены неподключёнными)
- iOS собирается на GitHub Actions (без подписи), CI настроен

### Не работает / ограничено

- **Оплата останавливается на «Stripe не сконфигурирован»** — функции не
  задеплоены, ключи не заданы (действие владельца, команды в QUICKSTART)
- **КУС и страховка — mock:** `verifyCarrier` принимает любой DOT (например
  12345), страховка возвращает фиксированную ставку; отметка «Проверен»
  пока ничего не гарантирует
- Отклик на заказ списывает баланс; у новых аккаунтов есть 5 бесплатных
  откликов, дальше нужно пополнение (упирается в пункт выше)

### Критические риски (блокеры продакшна)

4. 🟡 Главная страница читает всю коллекцию `deals`, фильтры на клиенте
5. 🟡 Google Maps API-ключ не ограничен по домену (в `app/web/index.html`)
6. 🟡 Нет админ-модерации верификации, нет Crashlytics, тесты — заглушки

### На проработке: физлица-перегонщики

Дать частным лицам возможность перегонять авто. Ключевое: требование DOT/MC
зависит от характера перевозки (for-hire interstate требует авторитета FMCSA
даже от физлица-sole proprietor), поэтому «просто отключить проверку» нельзя —
нужен ответ юриста. Предложено: `carrier_kind: company|individual` (без третьей
роли в `UserType`), КУС для физлиц через Stripe Identity (личность + права) и
Checkr (MVR + криминальный фон), страховка как обязательное условие допуска.
Оценка ~1,5–2 недели. Полностью расписано в ARCHITECTURE.md.
